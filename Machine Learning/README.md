## how it was done

- **one shared problem:** the prompt-injection data runs through A1, A5, A7, A8, A9 and A10, so every model is compared with
  the ones before it. A2, A3 and A4 come from one handout with fixed Kaggle datasets, filtered by name and roll number
- **nothing heavy on the laptop:** notebooks, training, app tests, screenshots and the PDF + Word reports all ran on Kaggle's
  free computers (see each assignment's `kaggle/` folder)
- **Lisa submissions:** `lisa/scripts/assignments.py submit` with a dry run first, then read back from Lisa to check
- **Classroom submissions:** Google's API can't attach files or turn in work on assignments a teacher created, so the CLI
  uploaded the files to Drive (made public), the browser attached them, posted the comment and pressed "Turn in"
