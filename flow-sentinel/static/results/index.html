Every model from the course,on the same test

The case study asks for six algorithms. All 11 classifiers taught in the syllabus were trained on the same 3,44,246 flows and scored on the same 1,14,749 locked test flows. For an intrusion detector the number that matters most is recall: of the real attacks, how many were caught.
