### Quiz mechanics learned
- Only the **two badge quizzes** (Week 4 = quiz id 76514, Week 8 = id 76515) count toward the badge; sessions 1/2/3/5/6/7 quizzes are practice only.
- Grading method **Highest grade**, so a weak attempt cannot lower the final grade; failing costs a 24h cooldown only.
- Attempt-weighted: 3 tries per question (true/false gets 1), first-try correct scores highest.
- Answers save on "Next page" — navigating by direct URL discards unsaved input.
- Q8 (scientific notation) uses an OU **supsub** editor: the visible contenteditable does not reliably sync to the submitted textarea; set both, e.g. `1.2x10<sup>24</sup>`.
