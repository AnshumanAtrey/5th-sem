Common project management frameworks

You’ve learned that project management frameworks define how project teams navigate the core phases of a project. Let’s find out what this means.

A project management framework is a standardized set of guidelines, processes, and tools that helps PMs and teams work consistently and efficiently throughout all phases of a project while staying aligned with the project goals.

In simpler words, project management frameworks are different ways to approach a project.

But why might PMs need alternative approaches to project?

To explore this, consider the following two projects:

•

Construction of bridge: For engineers and construction teams, the design and safety considerations of a bridge are complex. Making changes midway through the construction process might be costly and difficult, so the project team needs a fixed, step-by-step approach.

•

Music streaming app development: User preferences for music, playlists, and recommendations change frequently. Because these preferences evolve with trends and personal tastes, the project team requires a flexible approach so that they can continuously update the app’s features and interface.

Did you notice how these two projects have unique scope, constraints, and objectives?

PMs need different approaches to projects and the frameworks serve different purposes, helping PMs tailor their approach and address specific project characteristics and challenges.

Next, you’ll learn about each of these frameworks in detail, starting with Waterfall.

Important note: As you review the frameworks, you might notice that each framework has its own terminology and specific phases. Stay focused and remember the following points:

Each framework is built on the four core phases of a project management lifecycle.

The difference is how each framework organizes these core phases to guide the project teams. For example, in one framework, the project teams complete each phase in a fixed order before proceeding to the next phase, and in another framework, the teams continuously revisit and refine work from the previous phase.

As you explore the different frameworks, focus on how each framework supports the project team.
