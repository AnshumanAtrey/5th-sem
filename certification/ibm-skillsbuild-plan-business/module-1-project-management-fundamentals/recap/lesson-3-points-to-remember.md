Points to remember

Key concepts

1

A project management lifecycle is a series of phases that guide a project from initiation to completion.

2

The four core phases in a project management lifecycle are:

Phase 1: Initiate and plan a project

Phase 2: Execute the project

Phase 3: Monitor and control the project

Phase 4: Close the project

3

A project management framework is a standardized set of guidelines, processes, and tools that helps PMs and teams work consistently and efficiently throughout all phases of a project.

4

The three common project frameworks that PMs can use to address specific project characteristics and challenges are Waterfall, Agile, and Hybrid.

5

Waterfall is a traditional and sequential project management framework where the project teams complete tasks in several phases that follow a linear order. The following are the phases in this framework:

Phase 1: Analyze requirements

Phase 2: Design

Phase 3: Develop

Phase 4: Test

Phase 5: Deploy

6

Agile is a flexible framework that values adaptability, continuous improvement, and high level of collaboration where teams break down work into small, manageable iterations. The following are the phases in this framework:

Phase 1: Conceptualize and initiate

Phase 2: Plan for iterative development

Phase 3: Develop and execute

Phase 4: Review and gather feedback

Phase 5: Release and improve continuously

7

Hybrid is a flexible framework that blends elements of both Waterfall and Agile. The following are the phases in this framework:

Phase 1: Analyze requirements

Phase 2: Design

Phase 3: Develop and release iteratively

8

The following are the various factors that influence the PM’s decision to select a framework:

Project complexity and size

Stakeholder involvement

Project scope and deliverables

Time and resource constraints

By understanding the project management lifecycle and evaluating various frameworks, PMs can make informed decisions that address their project’s unique needs, ensuring efficient execution and successful project outcomes.
