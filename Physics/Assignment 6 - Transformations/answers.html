Q1. Write a short note on Translation Transformation. Explain how the position of a 2D object changes using the translation matrix. [2]

Translation moves every point of an object by the same amount in the x and y directions, without rotating, resizing or distorting it. The shape slides to a new position but stays identical. Example: dragging an icon across the screen.

A point (x, y) shifted by (tx, ty) becomes:

x' = x + tx y' = y + ty

Translation is an addition, not a multiplication, so to keep all transformations as matrix multiplications we use homogeneous coordinates (add a 1 as a third coordinate). The translation matrix is:

[ x' ] [ 1 0 tx ] [ x ] [ y' ] = [ 0 1 ty ] [ y ] [ 1 ] [ 0 0 1 ] [ 1 ]

Multiplying this out gives x' = x + tx and y' = y + ty, which is exactly the slide. Writing it as a matrix lets us chain translation with rotation and scaling in one combined matrix.

Q2. Write a short note on Rotation Transformation. Mention the role of the angle of rotation and the centre of rotation. [2]

Rotation turns an object about a fixed point by a given angle. The shape and size stay the same; only its orientation changes. Example: rotating a photo by 90°.

Rotating a point (x, y) by angle θ about the origin (anticlockwise positive):

x' = x·cosθ − y·sinθ y' = x·sinθ + y·cosθ [ x' ] [ cosθ −sinθ ] [ x ] [ y' ] = [ sinθ cosθ ] [ y ]

Role of the angle of rotation (θ): it sets how much the object turns, and its sign sets the direction (positive = anticlockwise, negative = clockwise). At θ = 0 nothing moves.

Role of the centre of rotation: it is the pivot the object turns around. The formulas above assume the pivot is the origin. To rotate about any other point (a, b), you first translate the object so that point moves to the origin, then rotate, then translate back:

translate(−a, −b) → rotate(θ) → translate(+a, +b)

So the centre decides where the turn happens, and the angle decides how far.

Q3. What is the purpose of Scaling Transformation in computer graphics? Would you prefer these as easy/basic or application-based questions? [1]

Scaling changes the size of an object by multiplying its coordinates by scale factors sx and sy (x' = sx·x, y' = sy·y). s > 1 enlarges, 0 < s < 1 shrinks, and equal sx = sy keeps the proportions while unequal values stretch the shape. Its purpose is to zoom in and out, fit objects to different screen sizes, and build models at the right relative dimensions. Like translation and rotation, it is done with a matrix so it can be combined with the others.

Preference: I would prefer a mix that leans application-based. The basic definitions are quick to memorise, but you only really understand transformations when you apply them, for example working out the matrix to rotate a shape about a corner instead of the origin, or combining scale-then-translate to zoom toward the mouse pointer. Application questions test whether you can actually use the maths, not just recall it.
